# ADR-0003：设备方向能力探测的安全边界

> 日期：2026-08-26  
> 状态：已接受  
> 适用阶段：M3-B01

## 决策

本阶段只探测浏览器是否处于安全上下文、是否暴露 `DeviceOrientation` 能力，以及是否存在需要用户手势授权的接口。探测由用户点击触发，不自动请求权限，不注册方向事件监听，也不读取或保存设备方向。

探测失败或浏览器不支持时，页面必须保持 M3-A 的手动角度输入和学习模式，并明确说明原因。探测成功也只能显示“环境支持”，不能把能力探测包装成实际测量结果。

## 进入 M3-B02 的条件

只有在 HTTPS、权限引导、平台差异、校准提示和真机测试矩阵确定后，才可以注册方向事件并更新罗盘角度。任何真实读数都必须显示测量限制、波动和校准状态。

## 影响

能力判断逻辑位于 `core/compass/sensor.ts`，浏览器 API 读取仅位于页面组件；这样可以用纯单元测试验证所有回退分支，也不会让自动化测试或普通桌面浏览器意外触发权限请求。
