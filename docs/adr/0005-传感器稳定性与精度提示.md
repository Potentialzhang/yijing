# ADR-0005：传感器稳定性与精度提示

> 状态：已接受（短窗口稳定性已实现，真机校准待验收）  
> 适用阶段：M3-B03  
> 日期：2026-08-26

## 背景

设备方向事件可能因磁场、姿态、屏幕旋转和平台实现产生波动。浏览器事件本身不能证明绝对测量精度，因此页面需要帮助用户识别“当前读数是否暂时可重复”，但不能给出精度保证。

## 决策

1. 对最近最多 8 个有效航向样本计算环形平均和相对平均值的最大角距离，避免 359°/0° 跨边界时被错误判为大幅波动。
2. 少于 4 个样本显示“正在收集”；达到 4 个样本且最大波动不超过 5°显示“短窗口内较稳定”，否则显示“短窗口内波动较大”。这些阈值是产品提示参数，不是设备精度标准。
3. 波动较大时提示远离磁铁、金属和电流设备，并缓慢转动设备重新观察；所有传感器读数继续标记 `accuracy: unknown`。
4. 稳定性状态只保存在当前页面运行时，不写入坐向记录；停止读取、切换模式、恢复记录和组件卸载时清空样本。
5. M3-B04 才引入用户可见、可重置并带历史说明的手动偏差修正；在真机矩阵完成前，不自动校准、不估算磁偏角，也不将稳定状态用于二十四山或现实决策。

## 验收依据

- 纯函数测试覆盖 0°/360° 跨边界、稳定、波动和样本不足分支；
- 真实 iOS Safari 与 Android Chrome 仍需验证样本频率、屏幕旋转、磁干扰和用户理解度；
- 发布文案必须同时出现“稳定性提示”和“精度未知”，不能只展示一个稳定角度。
