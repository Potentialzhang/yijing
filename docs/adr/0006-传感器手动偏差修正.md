# ADR-0006：传感器手动偏差修正

> 状态：已接受（代码已实现，真机语义与效果待验收）  
> 适用阶段：M3-B04  
> 日期：2026-08-26

## 背景

不同设备或使用环境可能存在用户已经观察到的固定偏差。工具可以记录用户明确提供的修正，但不能从一次读数自动推断校准值，也不能把修正值误认为磁偏角。

## 决策

1. 修正值范围为 `-180°` 至 `+180°`，保留 0.1°；展示当前生效值，并提供“一键重置为 0°”。
2. 每次应用或重置都追加一条 `CompassCorrectionRecord`，包含 ID、修正角、用户可读原因和时间；最近 5 条在页面展示，完整历史纳入 JSON 备份、导入合并、清空和当前 Dexie v9（此前 v8）。
3. 修正只作用于实时设备方向航向：`corrected = normalize(raw + offset)`。手动角度、八方几何映射、坐向记录和稳定性阈值不受影响。
4. 修正角不自动推断、不自动同步、不用于二十四山、流派判断、磁偏角或现实决策。传感器结果仍标记 `accuracy: unknown`。
5. 读取开始前的手动角度作为回退基准；停止读取后恢复该角度，用户若要保存传感器观察，必须主动手工输入并保存。

## 验收依据

- 纯函数覆盖正负修正、跨 0° 边界和范围限制；
- 备份协议覆盖修正记录字段、范围和重复主键；
- 真机需确认不同平台的读数方向、修正正负号和用户是否能理解“修正不是校准”。
