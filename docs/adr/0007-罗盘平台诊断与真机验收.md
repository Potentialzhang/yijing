# ADR-0007：罗盘平台诊断与真机验收

> 状态：已接受（诊断代码已实现，真实设备矩阵待完成）  
> 适用阶段：M3-B05  
> 日期：2026-08-26

## 背景

方向事件在 iOS Safari、Android Chrome、桌面浏览器之间存在接口和字段差异。自动化浏览器可以验证 UI 生命周期，却不能证明真实磁场、权限弹窗、姿态或设备校准行为。

## 决策

1. 用户点击“检测设备能力”后，页面生成平台诊断：平台类别、浏览器类别、安全上下文、方向事件 API、授权接口、屏幕方向 API 和当前读取路径。
2. 平台识别只基于浏览器公开的 UA、vendor、platform 和触摸点信息，用于选择验收路径，不作为设备型号或传感器准确度证明。
3. 诊断信息只在本地页面显示，不上传、不写入坐向记录；真实矩阵至少覆盖两类 iOS Safari 和两类 Android Chrome，并记录授权、拒绝、旋转、事件字段、磁干扰、稳定性、修正正负号和停止回退。
4. 在矩阵完成前，M3-B05 状态保持“待真机验收”；不能因为 Chromium/WebKit 自动化通过而标记真机完成。
