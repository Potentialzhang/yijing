# 账户与数据库迁移计划

## 本轮已落地

- PostgreSQL 16，Docker Compose 自动启动并持久化到 `yijing-postgres` volume。
- `scripts/migrate.mjs` 采用版本号表 `schema_migrations`，启动时按顺序执行增量 DDL，重复启动幂等。
- `users`、`sessions`、`user_records` 三张基础表，并一次性建立笔记、收藏、复习、进度、偏好、推演、罗盘、勘误和 AI 审计表；密码使用 scrypt，登录态使用 HttpOnly、SameSite=Lax 会话 Cookie。
- `/account` 页面支持注册、登录、退出；`/api/auth/me` 不缓存，认证接口只在服务端访问数据库。
- 运行容器使用非 root 用户，数据库不暴露宿主机端口，应用通过内部网络访问 PostgreSQL。

## 一键运行

```bash
cp .env.example .env
# 至少修改 POSTGRES_PASSWORD；如启用 AI，再填写 OPENAI_*。
docker compose up -d --build
docker compose ps
curl http://127.0.0.1:3000/api/health
```

局域网访问 `http://电脑局域网IP:3000`，账户入口为 `/account`。

## 正式数据接管阶段（已完成）

1. **账户基础（已完成）**：注册、登录、会话、数据库迁移和容器编排。
2. **正式表结构（已完成）**：个人业务表已一次性建立，不采用旧浏览器数据迁移。
3. **服务端 API 接管（已完成）**：笔记、收藏、复习、进度、偏好、来源模板和工具记录全部改为登录后调用 PostgreSQL API。
4. **移除浏览器数据层（已完成）**：客户端不再创建浏览器数据库或保存个人学习数据；跨标签仅使用无数据刷新信号。
5. **安全上线（后续增强）**：增加 CSRF token、登录限流、密码重置、邮箱验证、账户删除、审计日志和 HTTPS；公网部署前不得只依赖 Origin 校验。
