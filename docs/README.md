## 默认决策

- 首发形态：响应式 Web 应用，优先桌面与手机浏览器，后续支持 PWA 安装。
- 首发对象：单用户、个人使用，不做社区、付费和公开内容平台。
- 数据策略：账户优先，登录后使用个人数据；PostgreSQL 持久化，支持用户主动 JSON 导入导出。
- MVP 学习范围：阴阳、五行、八卦、六十四卦结构与爻变。
- MVP 暂不包含：复杂罗盘、自动吉凶判断、多人协作、社交和多流派综合断卦。
- 内容原则：经典原文、编辑释义、程序计算、外部观点和个人笔记分别存储、分别展示。

## 产品成功的最小判断

MVP 不是以“收录内容数量”衡量，而是要让用户完成以下闭环：

1. 学习一个知识点；
2. 不看答案完成一次回忆或推演；
3. 系统记录结果并安排后续复习；
4. 用户能够回看错误、补充个人笔记并导出数据。
